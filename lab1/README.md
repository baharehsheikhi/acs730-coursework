Instructions for this section will be provided in class and on Blackboard when we reach it.

Put your work for Lab 1 in this folder.

create-security-group.sh
It creates an AWS security group that allows SSH access only from my current IP address, following the principle of least privilege.


create-instance.sh
It automatically launches a small Amazon Linux EC2 instance with the required IAM role and name.


delete-instance.sh
It finds the EC2 instances with the specified name and terminates them.


delete-security-group.sh
Deletes the AWS security group named acs730-week1-sg and confirms that it was deleted.
